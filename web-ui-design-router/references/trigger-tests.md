# Trigger tests

Use these as behavioral tests, not as fixed wording templates.

## Positive routes

- “Design an AI model management console with tenant permissions and evaluation tables.” → `tech-blue-b2b-ui`
- “Build a cloud cost dashboard with dense filters and drill-down.” → `tech-blue-b2b-ui`
- “Create a factory equipment fault and work-order console.” → `industrial-orange-b2b-ui`
- “Design a warehouse exception-handling dashboard.” → `industrial-orange-b2b-ui`
- “Build a photovoltaic plant efficiency and carbon dashboard.” → `green-operations-b2b-ui`
- “Create a park energy-operations portal.” → `green-operations-b2b-ui`
- “Make a 16:9 real-time security command wallboard.” → `dark-cockpit-ui`
- “Create an operations center live situation screen.” → `dark-cockpit-ui`
- “Design appointment booking and lab-report explanation for patients.” → `patient-medical-web-ui`
- “Create prescription, payment, and family-proxy flows.” → `patient-medical-web-ui`
- “Build a diabetes daily tracking and coaching portal.” → `health-management-web-ui`
- “Design exercise, diet, and sleep trend plans.” → `health-management-web-ui`

## Negative routes

- API refactor with no visual surface → do not invoke this router.
- Marketing landing page without an application workflow → use a general frontend or brand-design skill.
- Native mobile app → these skills are Web-only.
