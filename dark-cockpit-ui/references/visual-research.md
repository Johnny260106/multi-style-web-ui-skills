# Visual research: command centers

For a new cockpit or major redesign, collect 12–20 current references across at least three sources, including two of Pinterest, Dribbble, Behance, and 花瓣; use 4–6 for a bounded module. Prefer recent work, and compare it with production monitoring and data-visualization guidance.

Search the mission and display context: `NOC monitoring wallboard`, `security operations command center`, `real-time situation awareness UI`, `large screen data visualization`, `指挥中心 大屏`, `态势感知 驾驶舱`, `实时监控 可视化`. Do not search only for “futuristic dashboard.”

Log URL, date if known, display type, transferable pattern, risk, and relevance. Compare distance hierarchy, alert salience, chart density, maps, timelines, refresh cues, acknowledgement, degraded mode, and detail reveal. Reject concepts that only work as a static poster.

Synthesize multiple sources; never copy a full composition, branded map, icon set, image, or proprietary visualization. Verify with realistic data and target resolutions.

Reject AI-default sci-fi signals: neon frames around every panel, cyan-on-black everywhere, tiny labels, gratuitous grids, fake radar, random particles, perpetual motion, excessive glow, symmetrical card walls, and decoration that competes with alarms.

If sources are blocked, use indexed previews or substitute without bypassing access controls. If browsing is unavailable or forbidden, disclose that the direction is not current-reference validated.
