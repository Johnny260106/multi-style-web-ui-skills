# Token direction

Accessible starting palette; test on target displays and ambient light.

- Canvas `#07111F`; base surface `#0B1726`; raised surface `#102238`; border `#294158`; strong border `#3A5A73`.
- Primary text `#E8F1F8`; secondary `#B7C7D6`; muted `#8EA3B5`.
- Brand/emphasis cyan `#22D3EE`; selected blue `#60A5FA`; focus `#67E8F9`. Use saturated accents sparingly.
- Success `#4ADE80`; warning `#FBBF24`; danger `#FB7185`; offline/unknown `#94A3B8`. Pair with label, icon, and shape.
- Chart grid lines should recede; important values and annotations must dominate. Avoid pure black and pure white expanses.

Use a 4px base scale and 4–6px radii. Size type for viewing distance: ordinary desktop body 14–16px; wallboard critical values materially larger. Never compensate for density with sub-12px text. Prefer tabular numerals and stable widths to reduce jitter.

Motion communicates refresh, transition, or alarm onset. Limit loops, offer pause when needed, and respect reduced motion.
