# Token direction

Accessible starting palette; validate actual foreground/background pairs.

- Canvas `#F5F5F3`; surface `#FFFFFF`; raised surface `#FAFAF8`; border `#DDD9D2`; text `#24211D`; secondary `#625D55`.
- Brand orange `#C2410C`; hover `#9A3412`; soft brand `#FFF1E8`. Brand orange identifies product and primary action.
- Caution `#A16207`, warning `#B45309`, danger `#B91C1C`, success `#047857`, offline `#59636E`, info `#0369A1`. Pair every operational state with text/icon, not color alone.
- Telemetry colors must be assigned by metric meaning and remain stable across pages.

Use a 4px spacing base, compact 32–40px controls where operators need density, 6px default radius, and minimal shadow. Use tabular numerals for telemetry and identifiers when supported. Always show units adjacent to values. Chinese labels need comfortable line height and must not be forced into abbreviations.

Motion is short and functional. New alarms may receive one bounded emphasis transition; never pulse indefinitely. Respect reduced motion.
