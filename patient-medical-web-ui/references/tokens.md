# Token direction

Accessible starting palette for a calm patient service. Adapt to the provider's brand without weakening status semantics.

- Canvas `#F4F8FB`; surface `#FFFFFF`; subtle surface `#F7FAFC`; border `#D6E1E8`; text `#17242E`; secondary `#52646F`.
- Trust blue `#0F6CBD`; hover `#0B5799`; active `#084576`; soft brand `#E8F2FB`; focus `#075985`.
- Positive `#19733B`; attention `#9A5B00`; urgent/danger `#B42318`; info `#075985`; unavailable `#5F6B75`. Medical abnormality must have text and context, not just a red token.
- Optional teal accent `#0F766E` is for secondary identity/data, not a universal “healthy” cue.

Use 4px base spacing, 8px default radius, restrained shadow, generous 16–24px reading rhythm, and 44px minimum target size for primary patient interactions when feasible. Default body 16px; never shrink medical explanations to fit. Use a Simplified-Chinese system sans stack with clear numerals.

Motion should orient, not delight during serious tasks. Use short transitions, no celebratory motion for medical results, and honor reduced motion.
