# Token direction

Accessible starting palette; validate actual combinations and chart colors.

- Canvas `#F3F7F5`; surface `#FFFFFF`; subtle surface `#F7FAF8`; border `#D7E2DC`; text `#18231D`; secondary `#52625A`.
- Brand green `#047857`; hover `#065F46`; active `#064E3B`; soft brand `#E7F6EF`; focus `#0F766E`.
- Success `#15803D` must remain a separate role even when visually related; warning `#A16207`; danger `#B91C1C`; info `#0369A1`; unknown `#59636E`.
- Data series should not be a monochrome green ramp when users must distinguish categories. Direct-label lines and bars where practical.

Use a 4px spacing base, 6–8px radii, and subtle elevation. Use tabular numerals for comparable metrics. Always display units, denominators, sign, reporting period, and baseline where relevant. Prefer a Chinese-capable system sans stack.

Use 140–220ms motion for state changes and drill-down continuity. Avoid decorative leaf motion and respect reduced-motion settings.
