# Enterprise patterns

- Shell: stable product navigation, contextual page title, environment/tenant identity, and utilities. Do not use breadcrumbs as the only orientation.
- List workspace: query summary, commonly used filters visible, advanced filters collapsible, active-filter chips removable, result count, saved view when justified, and bulk actions only after selection.
- Tables: left-align labels, right-align comparable numbers, expose units, keep row actions predictable, support sort/filter state, and provide a deliberate narrow-width alternative instead of squeezing every column.
- Detail: summary and current status first; group properties by user task; show timeline/audit history separately; keep the primary action stable.
- Forms: one clear submit outcome, field-level errors plus an error summary for long forms, unsaved-change handling, and permission-aware disabled explanations.
- Analytics: lead with the question and time range, annotate changes, expose comparison basis, include data freshness, and provide a table/text alternative for important charts.
- AI features: show source/context, confidence or limitation when meaningful, editable review before consequential actions, and explicit human confirmation.

On mobile Web, prioritize review and essential actions. Convert secondary columns into a disclosure/detail view; do not merely add horizontal scrolling to the whole page.
