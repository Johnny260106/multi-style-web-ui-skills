# Token direction

Use these as accessible starting points, not immutable brand values. Recalculate contrast for actual combinations.

- Canvas `#F4F7FB`; surface `#FFFFFF`; subtle surface `#F8FAFC`; border `#D9E2EC`; strong border `#B8C5D3`.
- Text `#172033`; secondary `#526173`; muted `#6B7788`.
- Brand `#2563EB`; hover `#1D4ED8`; active `#1E40AF`; soft brand `#EAF1FF`; focus ring `#1D4ED8` with an outer light offset.
- Success `#15803D`; warning `#B45309`; danger `#B91C1C`; info `#0369A1`. Never use brand blue as the only status cue.
- Data series: choose perceptually separated hues and provide patterns, labels, or direct annotations. Do not derive ten indistinguishable blues.

Use a 4px base spacing scale, 8–12px control gaps, 16–24px section rhythm, 4–8px radii, and restrained shadows only for elevation. Default body is 14–16px; dense table text may be 13–14px if zoom and line height remain usable. Prefer a Chinese-capable system sans stack; do not fetch a fashionable font without checking licensing, latency, and glyph coverage.

Motion should explain state: 120–180ms for controls, 180–240ms for panels, no continuous decoration. Respect `prefers-reduced-motion`.
